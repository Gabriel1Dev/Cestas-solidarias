# Requisitos e memória do projeto

Antes de alterar este aplicativo, leia `docs/REQUISITOS-CLIENTE-ORIGINAL.txt` e `docs/COMPATIBILIDADE-CLIENTE.md`. Este é um pedido explícito do usuário para manter compatibilidade com o cliente em todas as alterações futuras.

Preserve as decisões de escopo registradas na matriz. Verifique permissões, caminhos alternativos, banco e interface, além do fluxo principal; atualize evidências e pendências após mudanças. Não afirme conformidade integral apenas porque os testes existentes passaram. Sem envio ao GitHub sem pedido explícito. Testes de escrita somente em banco isolado.

O cadastro é usado durante uma entrevista presencial. Priorize preencher rapidamente em uma tela, começando pela identificação, usando dados já disponíveis e mostrando perguntas condicionais somente quando aplicáveis, sem afrouxar as validações.
